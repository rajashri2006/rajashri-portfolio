# Rajashri Portfolio

A responsive React + Vite portfolio for Rajashri I.

## Run locally
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Customize
- Replace `your-email@example.com` in `src/main.jsx` with your email.
- Add your resume PDF under `public/resume.pdf` and add a resume button if desired.
- Add GitHub links for individual projects when available.
